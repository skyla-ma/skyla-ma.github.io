Overview

In this project, I implemented image warping and mosaicing using homographies. By identifying corresponding points between overlapping photographs, I computed projective transformations to align the images. I then implemented nearest neighbor and bilinear interpolation for inverse warping, and used weighted averaging to blend images together into mosaics.

Part A.2: Recover Homographies

To align two images, I first selected corresponding points in their overlapping regions. I used recognizable features such as corners and edges of buildings to identify the same locations in both images. I then used these point correspondences to calculate a homography.

Computing the Homography

A homography maps a point from one image to another using a 3 by 3 matrix. Since the matrix is defined up to scale, I set its bottom-right entry to 1, leaving eight unknown parameters.

\[ \begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} \sim \begin{bmatrix} h_1 & h_2 & h_3 \\ h_4 & h_5 & h_6 \\ h_7 & h_8 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \]

Expanding the equations and rearranging gives two linear equations for each pair of corresponding points:

\[ \begin{aligned} xh_1 + yh_2 + h_3 - xx'h_7 - yx'h_8 &= x' \\ xh_4 + yh_5 + h_6 - xy'h_7 - yy'h_8 &= y' \end{aligned} \]

I stacked these equations for all point correspondences to construct a linear system \(Ah = b\). Since I used more than four point pairs, the system is overdetermined, so I solved for the homography parameters using least squares with np.linalg.lstsq. 

def computeH(im1_pts, im2_pts):
    n = im1_pts.shape[0]
    A = []
    b = []

    for i in range(n):
        x, y = im1_pts[i]
        xp, yp = im2_pts[i]

        A.append([x, y, 1, 0, 0, 0, -x*xp, -y*xp])
        A.append([0, 0, 0, x, y, 1, -x*yp, -y*yp])
        b.append(xp)
        b.append(yp)

    A = np.array(A)
    b = np.array(b)

    h = np.linalg.lstsq(A, b, rcond=None)[0]
    H = np.append(h, 1).reshape(3, 3)

    return H

Part A.3: Warp the Images

After computing the homography, I implemented image warping using inverse mapping. First, I transformed the four corners of the input image to determine the output bounding box. Then, for each pixel in the output image, I applied the inverse homography to find its corresponding location in the original image.

I implemented two interpolation methods to sample the source image at these coordinates.

Nearest Neighbor Interpolation

For nearest neighbor interpolation, I rounded the source coordinates to the nearest integer pixel location and copied that pixel value. This is simple and fast, but it can produce jagged edges and blocky artifacts when the image is enlarged or warped.

Bilinear Interpolation

For bilinear interpolation, I used the four neighboring pixels surrounding each source coordinate. I calculated a weighted average based on the horizontal and vertical distances from the source coordinate to those pixels. This produces smoother results, although it requires more computation than nearest neighbor interpolation.

\[ \begin{aligned} I(x,y) ={}& (1-d_x)(1-d_y)I_{00} + d_x(1-d_y)I_{10} \\ &+ (1-d_x)d_y I_{01} + d_xd_y I_{11} \end{aligned} \]

Image Rectification

To test my warping functions, I rectified images containing rectangular objects photographed from an angle. I selected the four corners of each object and defined a rectangular destination with the desired width and height. I then computed a homography between these points and warped the image using both interpolation methods.

Comparison

Both methods successfully rectify the objects into rectangular shapes. Nearest neighbor interpolation preserves the value of a single source pixel, which can make the output look more pixelated. Bilinear interpolation blends nearby pixels, making edges and textures appear smoother, although the difference is not very noticeable in my examples. I used bilinear interpolation for the final mosaics because it generally produces better-looking warped images.

Part A.4: Blend Images into a Mosaic

To create each mosaic, I chose one image as the reference and warped the second image into the reference image's coordinate system. I used the transformed corners to calculate the size of the combined canvas and placed both images onto it.

Simply placing one image over the other would create visible boundaries in the overlapping region. To reduce these seams, I implemented weighted averaging. Each image receives a weight that is larger near the center and decreases toward its edges. I also warped the weight map of the second image so that its weights align with the warped pixels.

In overlapping regions, I combined the images using:

\[ I_{\text{mosaic}}(x,y) = \frac{ w_1(x,y)I_1(x,y) + w_2(x,y)I_2(x,y) }{ w_1(x,y) + w_2(x,y) } \]

This helps blend the images smoothly while avoiding the hard boundary that would appear if one image completely overwrote the other. Some minor ghosting can still occur when the correspondences are imperfect or when there is parallax between the photographs.

Reflection

Some of my mosaics turned out better than others. The first mosaic has a fairly large overlapping region, which made it easier to select accurate correspondences. The second mosaic has a smaller overlapping region, which made it more difficult to find matching points, and the resulting mosaic had a warped building on the right. For the third mosaic, there is some stitching artifacts near the center-left, where the road and the ledge overlap unnaturally. The moving car may have contributed to this ghosting.

Overall, this project helped me understand how homographies can be used to align images taken from different viewpoints. One of the biggest challenges was selecting accurate point correspondences, since small errors could noticeably affect the alignment of the warped images. Implementing inverse warping and interpolation also helped me better understand how pixel values are sampled during geometric transformations.

I also learned that correctly aligning images is only part of creating a good mosaic. Blending is important for reducing visible seams, and even with weighted averaging, differences in perspective or camera position can still cause ghosting.
